PluginSMP

The whole plugin pack for BladeSMP — money, sell menu, and auction house. For Eaglercraft 1.8 / Spigot 1.8.8 servers.

⚡ Install EVERYTHING with one command

Terminal → cd into your server folder → paste. Running it again later updates every plugin (money and auctions are kept).

curl -sL https://cloudyiceocean.github.io/PluginSMP/install.sh | bash

Then restart the server. Done!
